What it does

Everything a mod manager should do

Import, toggle, reorder, diagnose, and roll back — without ever leaving a mess in your game folder.

Import anything

Drop a .zip, .rar, .oiv or a loose folder. Files are classified and routed automatically — ASI to root, scripts, loader DLLs, mods/ trees.

Toggle on and off

Mods live in an internal library. Replaced game files are backed up, and disabling or removing a mod restores the originals exactly.

Online-safe mode

One toggle parks every loader — dinput8, ScriptHookV.dll, root .asi, the mods/ folder — leaving the game byte-identical to vanilla.

Profiles

Named mod loadouts you switch between in one click. A "racing" set, a "screenshots" set — whatever you build.

Load order & conflicts

Reorder .asi and script files, and get flagged when two mods write to the same file — the one that loads last wins.

Dependency check

Detects Script Hook V, Script Hook V .NET and OpenIV.asi in your install, and links the official downloads for the missing ones.

Diagnostics

Parses ScriptHookV.log, asiloader.log, ScriptHookVDotNet*.log and Windows crash events, then surfaces the actual errors.

Game files browser

Browse .rpf archives OpenIV-style — extract, preview and replace files. Add-on and mods/-folder archives open with no keys.

Vanilla snapshot

Fingerprint your core game files while the folder is clean, then verify later whether anything drifted out of place.

Built to be trusted

No keys shipped. No account. No telemetry.

Ragekit reads RPF archives the same way OpenIV and CodeWalker do — using key material that only exists on your own machine.

Your executable, your key

The AES key is found by scanning your own GTA5.exe for the block whose hash matches the known value. Nothing is bundled with Ragekit.

NG data from CodeWalker

The NG key data is fetched at runtime from CodeWalker's public magic.dat and unscrambled locally with the key from your executable.

Open source, MIT

Every line is on GitHub. No installer bundleware, no background services, no data leaves your PC.

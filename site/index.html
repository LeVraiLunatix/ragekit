★ ★ ★ ☆ ☆ Solo uniquement

Ne lance jamais GTA Online avec Script Hook V ou des fichiers de jeu modifiés : ça peut faire bannir ton compte Rockstar. Le mode Online-safe de Ragekit sort tous les loaders du dossier en un clic, le jeu redémarre 100 % vanilla.

Fiche technique

Ce que ça fait

Importer, basculer, réordonner, diagnostiquer, revenir en arrière — sans jamais laisser un dossier de jeu en vrac.

  1. 01

    Import universel

    Un .zip, .rar, .oiv ou un simple dossier. Les fichiers sont classés et rangés tout seuls — ASI à la racine, scripts, DLL loaders, arbres mods/.

    zip · rar · oiv
  2. 02

    Activer / désactiver

    Les mods vivent dans une bibliothèque interne. Les fichiers du jeu remplacés sont sauvegardés ; désactiver un mod restaure l'original à l'identique.

    backup auto
  3. 03

    Mode Online-safe

    Un bouton met de côté tous les loaders — dinput8, ScriptHookV.dll, les .asi racine, le dossier mods/ — et laisse le dossier octet pour octet identique au vanilla.

    1 clic
  4. 04

    Profils

    Des configs de mods nommées que tu enclenches en un clic. Un set « course », un set « photo » — ce que tu veux.

    loadouts
  5. 05

    Ordre de chargement & conflits

    Réordonne les .asi et les scripts, et sois prévenu quand deux mods écrivent le même fichier — le dernier chargé gagne.

    diff fichiers
  6. 06

    Vérif des dépendances

    Script Hook V, Script Hook V .NET et OpenIV.asi détectés dans ton install ; liens officiels pour ceux qui manquent.

    SHV · SHVDN
  7. 07

    Diagnostic

    Parse ScriptHookV.log, asiloader.log, ScriptHookVDotNet*.log et les events de crash Windows, puis te sort l'erreur réelle et le module fautif.

    logs + WER
  8. 08

    Explorateur de fichiers du jeu

    Navigue dans les archives .rpf façon OpenIV — extraire, prévisualiser, remplacer. Les archives add-on et du dossier mods/ s'ouvrent sans clé.

    RPF v7
  9. 09

    Empreinte vanilla

    Prends l'empreinte de tes fichiers de jeu propres, puis vérifie plus tard si quelque chose a bougé.

    SHA-1
Sous le capot

Aucune clé distribuée

Ragekit lit les archives RPF exactement comme OpenIV et CodeWalker — avec du matériel de clé qui n'existe que sur ta machine.

ragekit — contrôle d'intégrité
[ OK ] clé AES lue depuis TON GTA5.exe (match SHA-1)
[ OK ] données NG récupérées via CodeWalker · magic.dat
[ OK ] déchiffrement RPF en local — rien d'exploitable stocké
[ OK ] aucun compte · aucune télémétrie · aucun service en fond
[ OK ] code source intégral sur GitHub · licence MIT
──────────────────────────────────────────────
> aucune clé Rockstar n'est fournie. il faut posséder le jeu.

Ton exécutable, ta clé

La clé AES est trouvée en scannant ton propre GTA5.exe — le bloc dont le hash correspond à la valeur connue. Rien n'est empaqueté avec Ragekit.

Données NG via CodeWalker

Le magic.dat public de CodeWalker est récupéré au runtime puis désembrouillé en local avec la clé de ton exécutable.
